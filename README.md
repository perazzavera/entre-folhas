# Entre Folhas 🌿

**Entre Folhas** é um e-commerce moderno e elegante para a venda de plantas e decoração. Este projeto foi desenvolvido de forma **totalmente autoral**, representando uma **empresa fictícia** que visa proporcionar aos seus usuários uma experiência única ao explorar uma variedade de produtos para decoração e cuidados com plantas. O projeto utiliza tecnologias como **React**, **Vite**, **TailwindCSS** e outras ferramentas poderosas para criar um site visualmente agradável, funcional e responsivo. 🌱

## 🚀 Tecnologias

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- **React**: Biblioteca JavaScript para construção de interfaces de usuário. ⚛️
- **Vite**: Ferramenta de construção rápida para projetos em React. ⚡
- **Tailwind CSS**: Framework CSS para criar layouts rápidos e responsivos. 🎨
- **MUI (Material UI)**: Biblioteca de componentes React para interfaces modernas. 🖥️
- **Preline**: Conjunto de componentes utilitários para acelerar o desenvolvimento. ⚙️
- **Embla Carousel**: Biblioteca para criar carrosséis responsivos e interativos. 🎠
- **React Router DOM**: Navegação declarativa para React. 🔄
- **React Toastify**: Biblioteca para exibir notificações tipo "toast". 🔔
- **ESLint**: Ferramenta para garantir que o código segue um padrão de qualidade. 🧑‍💻

## 📦 Instalação

Siga os passos abaixo para rodar o projeto localmente. 💻

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/entre-folhas.git
```

### 2. Navegue até o diretório do projeto

```bash
cd entre-folhas
```

### 3. Instale as dependências

Use o comando abaixo para instalar as dependências do projeto:

```bash
npm install
```

ou, se você estiver usando o **Yarn**:

```bash
yarn install
```

### 4. Rodando o projeto em desenvolvimento

Depois de instalar as dependências, rode o projeto localmente com:

```bash
npm run dev
```

Ou, se estiver usando o **Yarn**:

```bash
yarn dev
```

O projeto estará disponível em `http://localhost:3000`. 🌍

## 🛠️ Scripts

- **`dev`**: Inicia o servidor de desenvolvimento com Vite. 🏃‍♀️
- **`build`**: Cria a versão otimizada para produção do seu projeto. 📦
- **`preview`**: Pré-visualiza a versão de produção localmente após o build. 👀
- **`lint`**: Roda o ESLint para verificar e corrigir problemas de estilo de código. 🧹

## 🌍 Estrutura do Projeto

A estrutura do projeto segue uma organização modular, com cada componente em uma pasta própria.

- **src/**
  - **assets/**: Contém imagens, ícones e outros arquivos estáticos. 📸
  - **components/**: Contém os componentes reutilizáveis, como o Breadcrumbs e botões. 🔄
  - **pages/**: Contém os arquivos de página do site. 📝
  - **App.jsx**: Arquivo principal que configura a navegação e os componentes. 📂
  - **index.css**: Arquivo de estilo global. 🖋️
  - **index.jsx**: Ponto de entrada da aplicação React. 🏁

## ⚙️ Configuração

### Tailwind CSS

O projeto usa o **TailwindCSS** para estilização. Ele está configurado no arquivo `index.css` com o @theme. O Tailwind permite a criação de estilos responsivos e personalizados diretamente nas classes do HTML/JSX. 🖌️

### ESLint

O **ESLint** está configurado para garantir a qualidade do código e evitar problemas comuns. Para rodar o ESLint, use o comando:

```bash
npm run lint
```

### Vite

O **Vite** é usado para o desenvolvimento rápido e a construção do projeto. Ele lida com o empacotamento e otimização de módulos JavaScript. ⚡
